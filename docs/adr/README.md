# ADRs — registro de decisões de arquitetura

Uma decisão por arquivo: `ADR-00N-titulo-curto.md`. Modelo:

```
# ADR-00N — Título
Status: proposta | aceita | substituída por ADR-00M
Data: AAAA-MM-DD
Contexto: o problema e as restrições (cite specs e a constituição)
Decisão: o que foi escolhido
Alternativas consideradas: e por que foram descartadas
Consequências: o que fica mais fácil e mais difícil
```
