# K07 — Kitchenham & Charters (2007): diretrizes de RSL
Lido só nas seções 6.2–6.3 (65 páginas no total).
- §6.2.3: concordância entre pesquisadores por Cohen κ; registrar o κ inicial no relatório; discutir cada divergência; incerteza investigada por análise de sensibilidade; revisor único pode usar teste-reteste.
- §6.3.2: não misturar qualidade do estudo e qualidade do relato num só número; se misturar, dar menos peso ao relato.
- §6.3.3: o protocolo deve dizer como os dados de qualidade serão usados (seleção ou síntese); ponderar meta-análise por score não é recomendado pelas diretrizes médicas; usar instrumento por tipo de estudo.
